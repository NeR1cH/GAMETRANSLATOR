#  DeepL Game Translator v3.3

Профессиональный переводчик игровых файлов с поддержкой DeepL и Microsoft Translator.

##  Быстрый старт

### 1. Установка зависимостей

\\\ash
pip install requests
\\\

### 2. Настройка API ключей

Скопируйте \	ranslator_config.example.json\ в \	ranslator_config.json\:

\\\ash
copy translator_config.example.json translator_config.json
\\\

Откройте \	ranslator_config.json\ и добавьте свои API ключи:

#### DeepL API (бесплатно 500K символов/месяц)
1. Зарегистрируйтесь: https://www.deepl.com/pro-api
2. Скопируйте API ключ
3. Вставьте в \deepl_api_key\

#### Microsoft Translator API (бесплатно 2M символов/месяц)
1. Перейдите: https://portal.azure.com
2. Создайте ресурс "Translator"
3. Выберите план F0 (бесплатный)
4. Скопируйте KEY 1 и REGION
5. Вставьте в \microsoft_api_key\ и \microsoft_region\

### 3. Запуск

\\\ash
python GAMETRANSLATOR.PY
\\\

##  Возможности

-  Перевод из архивов (.zip, .tar, .tar.gz)
-  Поддержка JSON, TXT, YML, XML
-  Защита плейсхолдеров {PLACEHOLDER}
-  Автосохранение каждые 10 строк
-  Пауза/возобновление перевода
-  Проверка качества переводов
-  Браузер архивов
-  2 переводчика: DeepL + Microsoft

##  Использование

### Вкладка "Перевод"
1. Выберите тип перевода (файлы игры / обычный текст)
2. Выберите источник (архив/папка/файл)
3. (Опционально) Загрузите существующие переводы
4. Нажмите "Начать перевод"
5. Сохраните результат

### Вкладка "Применить"
1. Загрузите переводы
2. Выберите оригинальные файлы
3. Укажите папку для результата
4. Нажмите "Применить переводы"

### Вкладка "Проверка"
1. Загрузите переводы
2. Нажмите "Проверить качество"
3. При необходимости "Исправить ошибки"
4. Сохраните результат

### Вкладка "Конвертация"
1. Загрузите переводы
2. Выберите оригинальную структуру игры
3. Выберите папку для результата
4. Нажмите "Конвертировать"

##  Устранение неполадок

### Ошибка API ключа
- Проверьте правильность ключа в Настройках
- Для DeepL: ключ должен заканчиваться на \:fx\ (free) или быть без суффикса (pro)
- Для Microsoft: убедитесь что регион указан правильно

### Превышен лимит
- DeepL Free: 500,000 символов/месяц
- Microsoft Free: 2,000,000 символов/месяц
- Подождите до следующего месяца или купите платный план

### Не находит текст
- Убедитесь, что файлы содержат английский текст
- Проверьте формат файлов (.txt, .json, .yml, .xml)

##  Формат переводов

Переводы сохраняются в формате:
\\\
оригинал = перевод
\\\

Пример:
\\\
Hello World = Привет Мир
{PLAYER} joined the game = {PLAYER} присоединился к игре
\\\
