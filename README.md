## ✨ Возможности

### 🎮 Перевод игровых файлов
- **Автоматическое извлечение английского текста** из игровых файлов
- Поддержка форматов: `.txt`, `.json`, `.yml`, `.xml`
- Работа с архивами: `.zip`, `.tar`, `.tar.gz`, `.tgz`
- Интеллектуальное распознавание игрового контента

### 📝 Массовая обработка
- Перевод одного файла, папки или целого архива
- Загрузка существующих переводов для пропуска дубликатов
- Прогресс-бар и детальное логирование
- Автоматическое сохранение промежуточных результатов

### 🔍 Проверка качества
- Автоматическая проверка переводов на:
  - Пустые переводы
  - Непереведённый текст
  - Отсутствие кириллицы
  - Подозрительно короткие фразы
- Автоматическое исправление найденных ошибок
- Детальная статистика и отчёты

### 🔄 Конвертация форматов
- Применение переводов к оригинальным файлам
- Сохранение структуры папок и файлов
- Автоматическая конвертация при переводе
- Поддержка пакетной обработки

### 🎨 Современный интерфейс
- Интуитивный GUI на базе Tkinter
- 4 специализированных вкладки
- Drag & drop поддержка (планируется)
- Тёмная тема (планируется)

## 🔑 Получение API ключа DeepL

### Бесплатный план (500,000 символов/месяц)

1. **Регистрация:**
   - Перейдите на [DeepL Pro API](https://www.deepl.com/pro-api)
   - Нажмите **"Sign up for free"**

2. **Заполните форму:**
   ```
   Email: ваш_email@example.com
   Имя: Ваше имя
   Пароль: надёжный_пароль
   ```

3. **Подтвердите email:**
   - Проверьте почту
   - Кликните по ссылке подтверждения

4. **Получите ключ:**
   - Войдите в личный кабинет
   - Перейдите в раздел **"API Keys"**
   - Скопируйте ключ (формат: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:fx`)

5. **Вставьте в программу:**
   - Запустите GameTranslator
   - Перейдите в **⚙️ Настройки**
   - Вставьте API ключ
   - Нажмите **💾 Сохранить**

### Тарифы DeepL

| План | Символов/месяц | Цена | Особенности |
|------|----------------|------|-------------|
| **Free** | 500,000 | $0 | Идеально для начала |
| **Starter** | 1,000,000 | $5.49 | Расширенный лимит |
| **Advanced** | 10,000,000+ | $25+ | Для крупных проектов |

## 📖 Подробное руководство

### 🌐 Вкладка "Перевод"

Основная вкладка для создания новых переводов.

#### Типы перевода

**🎮 Файлы игры**
- Извлекает только английский текст из кавычек `"..."`
- Игнорирует переменные типа `{variable}`, `%param%`
- Идеально для RPG Maker, Ren'Py, Unity

**📄 Обычный текст**
- Переводит весь текст построчно
- Для субтитров, диалогов, описаний

#### Источники

| Тип | Когда использовать | Пример |
|-----|-------------------|--------|
| **📦 Архив** | Игра в .zip архиве | `game_v1.0.zip` |
| **📁 Папка** | Распакованная игра | `C:\Games\MyGame\data\` |
| **📄 Файл** | Один конкретный файл | `dialogs.txt` |

#### Существующие переводы (опционально)

Загрузите готовые переводы, чтобы:
- Не переводить одинаковые фразы повторно
- Экономить лимит DeepL API
- Объединять несколько источников

```
Формат файла:
Hello = Привет
Good morning = Доброе утро
How are you? = Как дела?
```

#### Процесс перевода

1. **Сканирование:** Программа ищет все текстовые файлы
2. **Извлечение:** Выделяет текст для перевода
3. **Фильтрация:** Убирает уже переведённые фразы
4. **Перевод:** Отправляет запросы в DeepL API
5. **Сохранение:** Записывает результаты в файл

**💡 Совет:** Для больших проектов (~10,000+ фраз) переводите частями по 5,000 фраз.

### 📝 Вкладка "Применить"

Применяет готовые переводы к оригинальным файлам игры.

#### Когда использовать?

- ✅ У вас есть файл с переводами
- ✅ Нужно "вшить" переводы обратно в игру
- ✅ Хотите сохранить структуру файлов

#### Пошаговая инструкция

**Шаг 1: Загрузить переводы**
```bash
# Выберите файл формата:
Original text = Переведённый текст
Another line = Другая строка
```

**Шаг 2: Выбрать оригинальные файлы**
- **📄 Один файл** - для одного файла
- **📁 Папка** - для всей игры
- **📦 Архив** - для распаковки и обработки

**Шаг 3: Указать место сохранения**
- **📄 Файл** - если обрабатываете 1 файл
- **📁 Папка** - для сохранения структуры

**Шаг 4: Применить**
```
Нажмите "▶️ Применить переводы"
```

#### Результат

```
Исходная структура:
game/
  ├── data/
  │   ├── dialogs.txt    (оригинал)
  │   └── items.json     (оригинал)
  └── maps/
      └── map01.txt      (оригинал)

Результат:
translated_game/
  ├── data/
  │   ├── dialogs.txt    (переведён)
  │   └── items.json     (переведён)
  └── maps/
      └── map01.txt      (переведён)
```

### 🔍 Вкладка "Проверка"

Автоматическая проверка качества переводов.

#### Что проверяется?

| Проблема | Описание | Пример |
|----------|----------|--------|
| **Пустой перевод** | Отсутствует текст | `Hello = ` |
| **Текст не переведён** | Оригинал = Перевод | `Hello = Hello` |
| **Нет кириллицы** | Латиница вместо русского | `Hello = Privet` |
| **Подозрительно короткий** | Перевод < 30% от оригинала | `Very long text... = Да` |

#### Использование

```
1. Загрузите переводы (📄 файл или 📁 папку)
2. Нажмите "🔍 Проверить качество"
3. Просмотрите найденные ошибки
4. Нажмите "🔧 Исправить ошибки" (автоперевод)
5. Нажмите "💾 Сохранить"
```

#### Пример отчёта

```
Всего переводов: 1,250
✅ Корректных: 1,187 (94.96%)
❌ С проблемами: 63 (5.04%)

Типы проблем:
  • Пустой перевод: 12
  • Нет кириллицы: 38
  • Подозрительно короткий: 13
```

### 🔄 Вкладка "Конвертация"

Преобразует переводы из формата "список" в формат игры.

#### Зачем нужна конвертация?

**Формат переводов:**
```txt
Hello = Привет
Goodbye = До свидания
```

**Формат игры:**
```json
{
  "dialog1": "Привет",
  "dialog2": "До свидания"
}
```

Конвертация автоматически вставляет переводы в правильные места.

#### Настройка

**Шаг 1:** Загрузите переводы
**Шаг 2:** Выберите оригинальные файлы игры (для структуры)
**Шаг 3:** Укажите папку для результата
**Шаг 4:** (Опционально) Включите автоконвертацию

**Автоконвертация при переводе:**
```
☑️ Автоматически конвертировать при переводе

Если включено, новые переводы сразу сохраняются 
в формате игры без дополнительных действий.
```

## ❓ FAQ

### Общие вопросы

**Q: Программа бесплатная?**  
A: Да! Программа полностью бесплатная. Нужен только бесплатный API ключ DeepL (500,000 символов/месяц).

**Q: Сколько символов я могу перевести?**  
A: Бесплатный план DeepL: 500,000 символов/месяц. Примерно 50-100 тысяч слов.

**Q: Какие игры поддерживаются?**  
A: Любые игры с текстовыми файлами: RPG Maker, Ren'Py, Unity, GameMaker, Wolf RPG Editor и другие.

---

### Технические вопросы

**Q: Ошибка "API key is invalid"**  
A: 
1. Проверьте правильность API ключа
2. Убедитесь, что скопировали полностью (с `:fx` в конце)
3. Проверьте активацию аккаунта DeepL

**Q: "Quota exceeded" / Превышен лимит**  
A:
1. Вы использовали 500,000 символов за месяц
2. Подождите до 1-го числа следующего месяца
3. Или купите платный план DeepL

**Q: Программа не находит текст в файлах**  
A:
1. Убедитесь, что файлы содержат английский текст
2. Проверьте, что текст в кавычках: `"текст"`
3. Попробуйте режим "📄 Обычный текст"

**Q: Перевод неточный или странный**  
A:
1. DeepL - лучший переводчик, но не идеален
2. Используйте вкладку "🔍 Проверка"
3. Отредактируйте проблемные фразы вручную

**Q: Как скомпилировать в EXE?**  
A:
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name=GameTranslator GAMETRANSLATOR.py
```

---

### Производительность

**Q: Перевод идёт очень медленно**  
A: 
- Нормальная скорость: 2-3 секунды на фразу
- Это ограничение DeepL API
- Для 1,000 фраз потребуется ~40-50 минут

**Q: Можно ли ускорить перевод?**  
A: Нет, DeepL имеет rate limit. Но можно:
1. Использовать существующие переводы (пропуск дубликатов)
2. Переводить частями по ночам
3. Купить платный план DeepL (больше запросов/сек)
